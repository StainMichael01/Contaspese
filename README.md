# Contaspese

Web app personale per entrate, uscite e saldo del mese, con categorie automatiche e importazione
della lista movimenti della banca (Excel) e dei pagamenti Apple Pay (Comandi Rapidi).

I movimenti restano nel browser del telefono: in questo repository c'è solo il codice dell'app.

Su iPhone: apri il sito in Safari, tocca Condividi, poi "Aggiungi alla schermata Home".
